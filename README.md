# Little Homie POS

เว็บแอปสำหรับร้าน Little Homie Coffee มี 2 หน้า ใช้ฐานข้อมูลร่วมกันผ่าน Firebase Firestore (โปรเจกต์ `littlehome-pos`) เพื่อให้ออเดอร์จากมือถือลูกค้าขึ้นที่หน้าจอร้านแบบเรียลไทม์

- **`index.html`** — หน้าลูกค้า: ดูเมนู เลือกของ ใส่ตะกร้า แล้วกดสั่งซื้อ (ทานที่ร้าน/กลับบ้าน) พร้อมติดตามสถานะออเดอร์แบบเรียลไทม์
- **`staff.html`** — หน้าหลังร้าน: กระดานออเดอร์สด, จัดการเมนู, ระบบบันทึกแต้ม/แลกรางวัลลูกค้า (ต่อยอดจากไฟล์ POS เดิม), รายชื่อลูกค้า, ประวัติทำรายการ

## การใช้งาน

เปิดผ่าน GitHub Pages ของ repo นี้:
- ลูกค้า (แนะนำให้ทำ QR code ติดโต๊ะ): `https://sek-skulpone.github.io/littlehome-pos/`
- หลังร้าน: `https://sek-skulpone.github.io/littlehome-pos/staff.html`

ไม่ต้องติดตั้งอะไรเพิ่ม เป็นไฟล์ HTML ล้วน (React ผ่าน CDN, ไม่มีขั้นตอน build)

## ข้อควรทราบเรื่องความปลอดภัย

หน้า `staff.html` (จัดการเมนู/ออเดอร์) ยังไม่มีระบบล็อกอิน — ใครก็ตามที่มีลิงก์สามารถเข้าไปแก้เมนูหรือกดสถานะออเดอร์ได้ ส่วนแต้มสะสม/รายชื่อลูกค้ายังเก็บแบบเดิมในเครื่อง (localStorage) เหมือนไฟล์ต้นฉบับ จึงไม่ sync ข้ามเครื่อง ถ้าต้องการเพิ่มระบบล็อกอินพนักงานทีหลังสามารถทำเพิ่มได้
